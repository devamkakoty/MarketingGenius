# MarketingAgent

Marketing Agent is an application for businesses to perform customer segmentation with the click of a button and create customised ads and marketing content that is hyper personalised for each user.
Users can - 
- Create Youtube shorts
- Instgram Ads and Dms (Multimodal)
- Facebook Ads and Dms (Multimodal)
- Emais
- SMS/Text Messages.
